# thesis-board

毕业论文进度看板：一个无构建步骤的静态页面，手机可直接访问、直接编辑。

站点：<https://mountmiaa-sudo.github.io/thesis-board/>

- `index.html` — 单文件页面，内联 CSS/JS/SVG，无外部依赖
- `progress.json` — 数据源（每日计划、待办、里程碑、五阶段状态、更新日志）

## 本地优先

页面上的一切都可以直接点、直接改：点圆圈打勾、点日期开选择器、点文字就地写、拖进度条、点右上角齿轮改里程碑日期。

**改动立刻存在这台设备的浏览器里，不需要 token、不需要联网**，刷新也还在。底部会显示还有多少项没同步。

想让公开页面也更新，才需要点「同步」—— 这一步要一个只对本仓库有 Contents 写权限的细粒度 token（在齿轮里设置），并且设备能访问 `api.github.com`。同步失败不会丢数据，本地版本原样保留。

桌面端也可以由 Claude Code 的 `update-board` skill 在论文会话结束时自动更新 `progress.json` 并 push。

## 每日计划

当天写几条要做的事，全部完成时会有一段庆祝动画。跨天时已完成的自动收走，没做完的留到第二天。

仓库公开，仅存放进度性描述，不含数据、代码与论文正文。
